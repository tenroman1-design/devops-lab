# Лабораторная 14. Nginx и Ansible

## Что сделано:

Поднял виртуальную машину в [Cloud.ru](http://Cloud.ru) через Terraform. С первого раза ВМ не создалась: в зоне `ru-moscow-1c` закончились диски SAS. При первом запуске Ubuntu не смогла скачать пакеты для Docker. После подключения по SSH я обновил список пакетов, установил Docker и запустил приложение.

Затем написал плейбук, который ставит Nginx, включает конфиг прокси и добавляет сервис в автозагрузку. Nginx слушает порт `80`, а приложение в Docker доступно на `127.0.0.1:8080`. Так оба сервиса могут работать на одной машине. Перед перезапуском плейбук запускает `nginx -t`.

## Проверка

- Ansible подключился к ВМ по SSH. Команда `ansible web -m ansible.builtin.ping` вернула `pong`.
- При первом запуске плейбука проверка `nginx -t` прошла, после чего Ansible перезапустил Nginx. В конце было `changed=5` и `failed=0`.
- По публичному IP запрос к `/` вернул `HTTP 200` через прокси. Запрос к `/health` тоже вернул `HTTP 200`, а в теле было `OK` от самого Nginx.
- Через `tcpdump` посмотрел запрос на входе в бэкенд и увидел `X-Student-Name: Aleksei Loginov`.
- Запустил плейбук ещё раз. Получил `changed=0` и `failed=0`.

## Как запустить

В папке `ansible-nginx` лежат плейбук `nginx.yml`, список хостов `inventory.ini` и настройки Ansible `ansible.cfg`. Если запускать на другой ВМ, в `inventory.ini` нужно указать её IP, пользователя и путь к своему SSH-ключу.
```bash
cd ansible-nginx
ansible web -m ansible.builtin.ping
ansible-playbook nginx.yml --syntax-check
ansible-playbook nginx.yml
```
